# Skyrim Workbench

Scripts, guides, mod recommendations, and other resources for Skyrim.

## Contents

### Scripts

Utilities for maintaining and managing Skyrim installations.

- [Set-SteamSkyrimAcfBuildAndLock.ps1](scripts/steam/set-skyrim-acf-build-and-lock/README.md): Stops Steam from downloading, staging, or installing an unwanted Skyrim update while its manifest remains locked, preserving an older version required by your SKSE setup and mods.

### Documentation

Guides and reference material for setting up Skyrim, solving common problems, and monitoring FPS and VRAM use in game.

- [Downgrade Steam Skyrim](docs/steam/downgrade-steam-skyrim.md): Explains how to restore an earlier game version after an unwanted update by downloading the matching files directly from Steam.
- [Quality of life mod list for older PCs](docs/modding/older-pc-qol-mod-list.md): A setup focused on useful interface and gameplay improvements, with restrained graphics upgrades for older PCs and 3 GB graphics cards.

### Mods

Skyrim mods published from this repository.
